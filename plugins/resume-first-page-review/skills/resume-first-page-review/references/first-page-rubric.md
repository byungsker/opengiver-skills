# 첫 페이지 검토 기준

이 문서는 이력서 첫 페이지를 검토하기 위한 일반 기준이다. 특정 책, 채용 담당자, 회사의 결과를 보편적인 확률이나 규칙으로 취급하지 않는다.

## 재사용 가능한 원칙

- 채용 담당자가 후보자와 가치를 빠르게 파악할 수 있도록 고정되고 읽기 쉬운 첫 페이지 레이아웃을 사용한다.
- 일반적인 직무명만 적기보다 의미 있는 제목이나 가치 주장을 앞세운다.
- 차별화된 강점은 적은 수만 보이게 하며, 보통 강하고 목표와 관련된 두세 가지 신호가 긴 목록보다 낫다.
- 각 강점을 기술 목록으로 끝내지 말고 결과, 측정값 또는 구체적인 증거와 연결한다.
- 첫 페이지가 관심을 만들고, 뒤의 섹션이 근거를 깊게 하며, 상세 경력이 신뢰성 질문에 답하도록 문서를 배치한다.

## 가설로 남는 것

- 특정 사례의 합격률 개선은 채용 확률 모델이 아니다.
- “Notion은 나쁘다”, 프로필 사진 의무, 특정 이미지·PDF 형식의 보편적 우위, 고정된 초 단위 규칙은 일반 법칙이 아니다.
- 시각적으로 눈에 띄는 첫 페이지도 약한 직무 적합성, 확인할 수 없는 소유 범위, 접근할 수 없는 텍스트, 깨진 최종 PDF를 보완할 수 없다.

## 검토 질문으로 바꾸기

원칙을 다음 질문으로 바꿔 검토한다.

1. 채용 담당자가 한 번 훑어본 뒤 후보자의 가치 주장을 말할 수 있는가?
2. 경력을 부풀리지 않고도 후보자를 구분할 만큼 정체성이 구체적인가?
3. 보이는 강점이 목표 직무와 직접 관련되어 있는가?
4. 눈에 띄는 각 주장에 방어 가능한 증거 연결이 있는가?
5. 실제 산출물이 위계, 가독성, 링크, 페이지 흐름을 유지하는가?

보이지 않는 페이지, 제공되지 않은 직무 공고, 검증되지 않은 수치에 답이 달려 있다면 근거 없는 주장으로 빈틈을 채우지 말고 결과를 `unknown` 또는 `BORDERLINE`으로 표시한다.
